Abstract

These types define the general function contract and common support for input and output vectors, compound functions, and transformed functions.

class analyticFunction : public dtOO::labelHandling, public dtOO::renderInterface

Abstract base class for analytic mappings between vector spaces.

An analytic function maps an input vector of type aFX to an output vector of type aFY. Derived classes define the input and output dimensions, input bounds, evaluation, cloning, and transformation behavior.

Input percent coordinates are normalized to [0, 1] in each direction. Convenience overloads evaluate one-, two-, and three-dimensional functions and return their output components as standard vectors.

Subclassed by dtOO::scaFunction, dtOO::vec2dFunction, dtOO::vec3dFunction
