class analyticGeometry : public dtOO::labelHandling, public dtOO::renderInterface

Abstract base class for parameterized analytic geometries.

Derived classes represent curves, surfaces, or volumes embedded in three-dimensional space. They define the parameter-space dimension and bounds and evaluate points and first derivatives in native coordinates.

Percent-coordinate helpers map each parameter from [0, 1] to its native range. Bounding boxes and their length, area, or volume measures are calculated lazily from a regular parameter-space sample grid.

Subclassed by dtOO::analyticGeometryGroup, dtOO::map1dTo3d, dtOO::map2dTo3d, dtOO::map3dTo3d, dtOO::multipleBoundedSurface, dtOO::multipleBoundedVolume

class map1dTo3d : public dtOO::analyticGeometry

Abstract one-dimensional map embedded in three-dimensional space.

This class represents a parameterized curve p(u). Concrete implementations provide point evaluation, creation, cloning, and transformation. Native parameter values lie in [getUMin(), getUMax()], while percent variants use the normalized interval [0, 1].

The optional operations provide numerical derivatives, curve segments, arc-length conversions, rendering, and closest-point reparameterization.

Subclassed by dtOO::analyticCurve, dtOO::scaOneDInMap1dTo3d, dtOO::vec2dOneDInMap2dTo3d, dtOO::vec3dOneDInMap3dTo3d

class map2dTo3d : public dtOO::analyticGeometry

Abstract two-dimensional map embedded in three-dimensional space.

This class represents a parameterized surface p(u, v). Concrete implementations provide native-coordinate point evaluation, creation, cloning, and transformation. Percent-coordinate variants use normalized u and v values in [0, 1].

It provides common surface operations including derivatives, normals, Jacobians, closest-point reparameterization, boundary curves, and trimmed curve or surface segments.

Subclassed by dtOO::analyticSurface, dtOO::rotatingMap1dTo3d, dtOO::trans4SidedFace, dtOO::vec2dTwoDInMap2dTo3d, dtOO::vec3dTwoDInMap3dTo3d

class map3dTo3d : public dtOO::analyticGeometry

Abstract three-dimensional map embedded in three-dimensional space.

This class represents a parameterized volume p(u, v, w). Concrete implementations provide native-coordinate point evaluation, creation, cloning, and transformation. Percent-coordinate variants use normalized coordinates in [0, 1] for every parameter direction.

Common helpers expose first derivatives, volume reparameterization, boundary surfaces, curve and surface segments, parameter bounds, and rendering resolutions.

Subclassed by dtOO::infinityMap3dTo3d, dtOO::radialTranslatingMap2dTo3d, dtOO::rotatingMap2dTo3d, dtOO::trans6SidedCube, dtOO::translatingMap2dTo3d, dtOO::vec3dThreeDInMap3dTo3d
