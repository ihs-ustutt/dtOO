Builders

Builders construct, modify, or evaluate analytic functions. They are utility classes and do not form part of the analytic-function inheritance hierarchy.

class vec3dTwoD_normalOffset

Builds a B-spline surface offset along projected base-surface normals.

Public Functions

vec3dTwoD_normalOffset(vec3dTwoD const *const v3d, vec3dTwoD const *const thick, dtVector3 const &nf, dtInt const &nU, dtInt const &nV, dtInt const &order, dtInt const &skinOrderMin, dtInt const &skinOrderMax, dtInt const &skinNIterations, bool const &closeU = false, dtReal const &closeSmooth = -1.)
Parameters:

  • v3d – Base surface mapping.

  • thick – Mapping whose x component is offset magnitude and y/z components are base-surface parameters.

  • nf – Reference vector used to project the surface normal.

  • nU – Number of samples in the first parameter direction.

  • nV – Number of samples in the second parameter direction.

  • order – B-spline order of generated section curves.

  • skinOrderMin – Minimum skinning order.

  • skinOrderMax – Maximum skinning order.

  • skinNIterations – Number of skinning iterations.

  • closeU – Whether to join the first and last sample rows.

  • closeSmooth – Optional seam-smoothing factor.

vec3dTwoD *result(void) const

Return a clone of the generated offset surface.
